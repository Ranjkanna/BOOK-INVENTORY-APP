## Book Inventory App

A responsive book inventory tracker built as part of freeCodeCamp's CSS Certification — Learn Advanced CSS Concepts by Building a Book Inventory App.

Overview

This project displays a table of books with their reading status and a star-based rating system, styled entirely with advanced CSS attribute selectors and gradients — no JavaScript required for the styling logic.

Features
Status-based row and badge styling — rows and status badges (Read, To Read, In Progress) are color-coded using linear-gradient backgrounds, selected purely via CSS attribute selectors ([class="..."]).
Star rating indicators — each book has a 1–3 star rating rendered as small circular elements, styled using attribute and descendant/sibling selectors ([class^="rate"], [class~="one"], [class~="two"], [class~="three"], :nth-child()).
Fully responsive layout using semantic HTML table markup.
***CSS Concepts Practiced**
Attribute selectors: [class="x"], [class^="x"], [class~="x"]
Descendant and child combinators
:nth-child() pseudo-class selection
linear-gradient() backgrounds
inline-block display for custom-styled inline elements
